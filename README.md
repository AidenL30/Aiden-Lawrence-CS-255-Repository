How did you interpret the user’s needs and implement them into your software design? Why is it so important to consider the user’s needs when designing?
Interpreting user needs is a crucial and integral step of developing any new software or updating said software. I feel that Users have a unique perspective compared to developers as they interact with the systems primary functions regularly and can easily detect any mishaps. I believe that any user feedback and input should be heavily considered when developing or changing any new or existing software.

How did you approach designing software? What techniques or strategies would you use in the future to analyze and design a similar software application?
When I approach software development, I always prefer to tackle different sections at different points in time. This allows me to reduce burnout as well as think much more clearly about the project. When I develop code for any project, I always cross reference any new object that I have built with existing structures in the project. This allows me to keep consistent with the existing structure as well as define my code much more efficiently.
